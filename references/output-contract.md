# 提示词输出约定

用户明确的语言、长度、格式、目标比例和改图要求优先于以下默认值。

## 默认交付

- 中文与英文各一段连贯的创作指令，各自包含一次目标画幅比例。正文不带分析字段、项目符号、Markdown 强调或解释。
- 优先顺序：主体与关系 → 构图与视角 → 媒介和光色 → 有辨识度的纹理及细节 → 必要保留项。依实际图片调整顺序，不强行覆盖所有字段。
- 中文最多 500 个非空白 Unicode 字符（标点计入），英文最多 500 个以空白分隔的单词；比例也计入。内容充足时可参考中文 180–470 字、英文 100–480 词。没有硬性下限，语义覆盖优先于字数。
- 两种语言保留同样的主体、数量、位置、动作、媒介和画幅，英文自然表达，不逐字堆砌关键词。
- 通过可见技法描述风格。不猜原图的模型、Seed、Steps、CFG、Sampler、LoRA 或拍摄器材来源。用具体视觉控制取代“8K”“masterpiece”等空泛质量词。
- 用户指定生成平台时，仅应用已确认的平台语法；参数是目标生成建议，不能说成原图参数。平台信息不确定时交付自然语言版本。

## 机器记录与校验

在临时工作目录保存 UTF-8 JSON 对象，默认只有 `zh`、`en` 两个非空字符串字段；JSON 是校验输入，不代表每次都向用户展示原始 JSON。用户仅要一种语言时只写该字段，并传 `--language zh` 或 `--language en`。

```json
{"zh":"以 1:1 方形画幅构图……","en":"Compose for a 1:1 square canvas…"}
```

`validate` 成功退出码为 0，输出计数与校验结果；不通过为 1，输入或用法错误为 2。检查字段、字数、预期画幅、冲突画幅和像素尺寸写法；不会改写提示词，也不能验证视觉事实、翻译准确度或最终出图效果。

用户明确放宽字数时，用 `--zh-max`、`--en-max` 指定相应上限；明确需要像素尺寸时可加 `--allow-pixels`。比例缺失应补写；冲突时重新检查构图含义后修改，不盲目全局替换数字。

## 交付前视觉核对

再次看图：关键构图关系是否写清，是否把平面媒介变成立体，是否新增看不见的对象，中英文是否互相矛盾。用户改动引起与原图不同的地方应符合请求，而不是被“还原”规则改回去。

用户要求拆解时，额外交付简短的视觉观察摘要，与可复制提示词分开。用观察事实解释结果，不输出隐藏推理、假装记录模型内部过程，或声称这些文字就是原作者使用的提示词。
