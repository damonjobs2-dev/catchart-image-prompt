# 视觉证据

先判断主媒介，再使用相关观察项。目标是保留决定相似度的信息，最终提示词不是检查表的逐项抄写。

## 共用观察

- **主体与关系**：主体是什么、数量、姿态、朝向、轮廓，元素之间的遮挡、相交、大小和距离关系。复杂图先保住主体与构图，再补辨识细节。
- **构图与空间**：居中或偏置、裁切、留白、视角、前中后景、视觉重心。用相对位置和尺度描述，避免无依据的精确坐标。
- **视觉语言**：可观察的媒介、边缘、笔触、颗粒、光线方向和软硬、主辅点缀色及各自分布。把“高级感”等形容词落到具体形状、光色与材质。
- **重建约束**：优先保留识别锚点与背景结构。目标比例变化时，必要的背景扩展、留白和裁切服从主体完整性。

## 按主媒介选择

| 类型 | 优先核对 | 常见误差 |
| --- | --- | --- |
| 摄影 | 透视、景深、景别、光源、反射与表面材质 | 把可见效果写成未知的相机型号、焦距或光圈 |
| 插画 / 绘画 | 线条、笔触、平涂或体积、造型简化程度、纸面或颜料纹理 | 自动补成写实照片或复杂 3D |
| 拼贴 / 海报 | 图层次序、几何遮挡、文字层级、图像和留白的关系 | 只列“人像、圆、条纹”，遗漏它们如何组合 |
| 产品图 / 3D | 外形、部件、材质、摆放、接触阴影、背景 | 猜测隐蔽结构、软件名或商品品牌 |
| Logo / 字体 | 字形、线宽、负空间、字距、基线、颜色与边缘效果 | 无证据增加摄影布光和环境 |
| 抽象图 | 形状、方向、节奏、疏密、相交与色彩分布 | 把几何形强行命名成具体物体 |
| 界面截图 | 容器、列、层级、对齐、间距、可见状态 | 用提示词承诺实现交互或自动复刻代码 |

混合媒介保留各区域对应的表现方式，例如“黑白照片裁片叠在红色平涂圆形之上”。

文字清晰且用户需要保留时逐字核对，标明文字内容与位置；不可读时描述文字块形态或预留区域。保持品牌、角色等用户指定内容时，仍需描述可见轮廓与色彩，不能用名字替代构图证据。签名和水印只在用户要求保留时纳入。

视图模糊、过小或关键区域不可见时，先尝试查看原图或局部；仍不清楚就省略不确定细节，必要时询问。纯色、空白和极简图片可以交付很短的提示词，不为满足长度编造内容。
